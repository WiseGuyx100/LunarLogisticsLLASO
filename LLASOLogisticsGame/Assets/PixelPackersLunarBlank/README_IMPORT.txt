PIXEL PACKERS / ORIGINAL MOON + EMPTY DOME

IMPORT
1. Download PixelPackers_OriginalMoon_EmptyDome.unitypackage. This file is already the import package; do not unzip it.
2. In your Unity 6 project choose Assets > Import Package > Custom Package.
3. Select this .unitypackage, click Open, then Import with all items checked.
4. Wait until importing and script compilation finish.
5. Tools > Pixel Packers Empty Lunar Dome > Open Scene.
   Or select Assets/PixelPackersLunarBlank/OPEN_SCENE and click Open Scene in the Inspector.
6. Press Play; click Game view. WASD move, mouse look, Shift sprint, Space jump, Escape cursor.

CONTENTS
Original lunar TerrainData, terrain layers, rock meshes/prefabs, textures and Milkyway sky.
New outer mountain backdrop. Empty glass dome with supporting ribs.
No loading building, labels, cargo, shelving, furniture, ramp, deck, office, tanks, pads or lane markings.
The dome interior is bare lunar soil. Rock placement is regenerated outside the dome.
Preview walker and invisible site boundaries are included.

EDITING
Stop Play. All scene objects are under Empty Lunar Dome / Habitat Layout.
The Open Scene shortcut creates and saves editable copies under PixelPackersLunarBlank/Generated.
The original TerrainData remains the source; its height data is copied before flattening.
Save after individual edits. Rebuild replaces the generated Habitat Layout subtree.
The older habitat scene is retained if previously imported; open LunarBlank_Demo for this version.
