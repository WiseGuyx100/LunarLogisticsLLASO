# Electric Tug — Heavy Duty Realism & Clear-View Edition

A high-detail, programmatically built Heavy-Duty Electric Cargo Tug for Unity with zero model clipping, perfect seams, and unobstructed driver line-of-sight.

## Features
- **Proportional Heavy-Duty Assembly**: Engineered with exact component positioning to eliminate Z-fighting, intersecting geometry glitches, and gaps.
- **Unobstructed First-Person Field of View**: The driver seat mount, angled dash, low-profile hood, and panoramic safety-glass cab provide a 100% clear line of sight.
- **Detailed Procedural Detailing**: Includes contoured wheel arches, industrial front bumper with rubber push pads, heavy rear towing hitch coupler, dual headlights + indicators, amber safety beacon, gauge dashboard, and molded driver seat.
- **Physics & Driver Controller**: Built-in heavy physics (4,500 kg mass, low center of gravity), smooth acceleration, regenerative braking, lateral tire grip simulation, and 4-zone approach entry/exit system.

## Setup Instructions
1. Copy the `ElectricTug_HeavyDuty_Pro` folder into your Unity project's `Assets/` directory.
2. Allow Unity to compile scripts.
3. In the top menu bar, click **GameObject → Logistics Game → Create Heavy Duty Electric Tug**.
4. Press **Play** in Unity and approach the tug from any side to enter (default key: **F**).

## Controls
- **F**: Enter / Exit Tug
- **W / S** (or **Up / Down**): Throttle / Reverse
- **A / D** (or **Left / Right**): Steer Left / Right
